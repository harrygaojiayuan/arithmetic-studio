Windows 版算数练习室，适用于 Windows 10 / 11 的 x64 电脑，可离线运行。

下载选择：

- `.exe`：安装版，按向导安装后从开始菜单或桌面打开。
- `.zip`：免安装版，完整解压后双击 `ArithmeticStudio.exe`。请保留同目录下的所有文件。
- `SHA256SUMS.txt`：安装包和压缩包的校验值。
- `Windows-smoke-test.json`：GitHub Windows 环境实际启动应用后的验证报告。

所有原有功能都已保留，包括题目参数设置、默认 10 分钟的可调倒计时、个人排行榜、错题回顾，以及答对变绿、答错变红并抖动。

除法规则：被除数大于除数且能整除；被除数排除 1 和所有质数，除数只排除 1，允许质数。

数据保存在 `%APPDATA%\ArithmeticStudio\data.json`。更新或卸载应用文件不会主动删除个人成绩。

此版本没有商业代码签名证书，Windows 可能会显示未识别的发布者提示。仅从本仓库下载并核对校验值。
